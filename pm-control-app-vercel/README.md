# PM Control App v2

**Apple-style local PM dashboard - Vercel/Netlify ready**

## Deploying on Vercel

1. Make a GitHub repo called `pm-control-app` (or any name you like).
2. Upload this `index.html` file in the root of the repo.
3. Login to [vercel.com](https://vercel.com), import your repo, deploy as a static site.
4. Your live link will look like: `https://pm-control-app-<yourvercelid>.vercel.app`

- Urdu/English local, fast, modern
- No backend/server needed
- All data is in browser storage (not in cloud)
